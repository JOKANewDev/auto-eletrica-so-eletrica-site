# ⚡ Autoelétrica Só Elétrica - Website

Link do Site: https://auto-eletrica-so-eletrica.netlify.app/

Este é o site institucional da **Autoelétrica Só Elétrica**, especializada em diagnóstico computadorizado e manutenção elétrica para veículos de linha pesada, máquinas e utilitários.

O projeto foi desenvolvido com foco em performance, design moderno (Dark Mode) e conversão direta via WhatsApp.

## 🚀 Tecnologias Utilizadas

* **HTML5**: Estruturação semântica.
* **CSS3**: Estilização customizada com variáveis, Grid Layout e Flexbox.
* **JavaScript**: Lógica do modal de agendamento e integração com API do WhatsApp.
* **Google Fonts**: Fontes Montserrat e Inter para legibilidade superior.
* **Font Awesome**: Ícones vetoriais para interface.

## 📋 Funcionalidades

- **Design Responsivo**: Adaptado para celulares, tablets e desktops.
- **Agendamento Inteligente**: Modal capturando dados do veículo e enviando formatado para o WhatsApp do técnico.
- **Catálogo de Serviços**: Exibição clara das soluções oferecidas com ilustrações modernas.
- **CTA Flutuante**: Botão de contato rápido via WhatsApp sempre visível.
- **Otimização de Imagens**: Uso de `object-fit` para garantir que as fotos dos serviços mantenham a proporção.
